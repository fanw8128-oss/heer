## 二、LOGO（矢量见 `brand/orrion-logo.svg`）

**标志构成**：相机**光圈(aperture)** 六叶片 + 中心**焦点(信号点)**。
- 五片墨绿叶片 = 系统/光学；
- 一片**琥珀色叶片** = "被捕获的那一束最早信号"；
- 中心琥珀焦点 + 微十字 = 精准对焦/瞄准。
- 外环 = 镜筒，呼应"光学"。

**为什么改**：旧版"准星+弧线"偏军工瞄准镜；新版"光圈+焦点"既是光学语义，又能跨科室通用，且更国际化、可缩放到极小尺寸（设备蚀刻、APP 图标均成立）。

**字标**：ORRION，几何无衬线、字重 800、字距 +14。中文"欧锐安"仅用于国内竖排副标。

**规范**：
- 主色 Deep Emerald `#0E7A5F` / Signal Green `#15A37B` / Amber `#E8A33D` / Ink `#10211C`。
- 最小留白 = 标志高度的 0.5×；最小使用尺寸：符号 16px、横排锁定 96px 宽。
- 禁止：拉伸、换色、加阴影、旋转叶片、在复杂底图上直接放彩色版（改用单色反白）。

**落地呈现**：
- **设备**：采集头后盖 + 机箱正面，单色阳极氧化/丝印（见 svg "ON-DEVICE"版），低对比、内敛。
- **彩页/PPT**：左上角横排锁定 + 大量留白；封面用"符号 + Slogan"。
- **开机/UI**：符号居中淡入，焦点琥珀点最后亮起（"信号被捕获"动效）。

## 三、台车系统架构（六大模块串联）

爆炸图见 `cart/orrion-exploded.svg`，外观图见 `cart/orrion-cart-render.svg`。

```
①采集头 ─(液芯光导/信号线)─ ②阻尼平衡臂 ─ ③主机/光源引擎机箱 ─ ④触控显示
                                              │
                                       ⑤移动底盘 ─ ⑥电源/电池(兼配重)
```

| # | 模块 | 核心件 | 功能 |
|---|---|---|---|
| 1 | 采集头 Optical Head | 物镜组 / 二向色镜 / 发射滤光片 / 单色CMOS / 投射准直 / 白光环LED / 防雾窗口 | **头内无光源**，只投射激发光 + 成像 |
| 2 | 阻尼平衡臂 Arm | 恒力弹簧 + 摩擦阻尼关节 | 任意位姿悬停；内走液芯光导 + 屏蔽信号线 + 接地 |
| 3 | 主机/光源引擎 Console | 340/450nm + 白光 LED + TEC恒温 + 光纤耦合器 + 采集卡 + AI算力 + 控制板 | 产生并耦合激发光；采集/重建/AI诊断 |
| 4 | 触控显示 Display | 15.6" 医用电容屏，-12°倾角，VESA快拆 | 实时热图 + AI结论 + 操作 |
| 5 | 移动底盘 Base | 钢架 + ABS包覆 + 4×Ø100医用脚轮(前2带刹) | 移动 + 低重心防倾 |
| 6 | 电源/电池 Power | 医用隔离电源 + LiFePO4 + UPS | 续航≥4h，底部布置兼作配重 |

### 关键架构决策：光源不在采集头里
- **问题**：340nm 紫外直接集成在头里 → 发热、热漂移、紫外随导光衰减、头部变重变烫。
- **方案**：把 340/450nm + 白光 **LED 引擎放进机箱③**，TEC 恒温 ±0.2℃、EMI 屏蔽；经**光纤耦合器**进入**液芯光导(Liquid Light Guide)**，沿平衡臂②内腔上行到采集头①的投射端口出射。
- **收益**：头轻(<0.9kg)、热稳定、紫外能量可控、维护只换机箱模块。
- 光路链（见 `cart/orrion-optical-path.svg`）：
  `机箱LED → 耦合器 → 液芯光导(沿臂) → 采集头投射口 → 体外 200mm 激发 → 组织荧光(NADH/FAD) → 物镜 → 二向色镜 → 发射滤光片 → 单色CMOS → 采集卡/AI`

### 工作方式（操作流程）
1. 推车到位、踩下前轮脚刹；开机，符号动效自检。
2. 握柄移动采集头至受检部位**体外 ~200mm**（非接触），屏幕十字辅助对焦。
3. 触发单帧采集：TDM 时分复用，340nm/450nm 微秒级交替，**总曝光 2s±0.5s**，激发光斑 >30mm。
4. 系统实时重建 NADH/FAD 代谢热图（绿=正常 / 红=高代谢可疑），输出 AI 分级与置信度。
5. 医生确认/存档，可叠加病理 OCR 输入。

## 四、外观设计语言（"百万级设备感"）

- **形面**：大圆角、整体感强的"一块料"机箱，分模线藏在功能缝（散热槽/盖板）。
- **配色**：云白主体 + 墨绿/琥珀点缀（品牌色），采集头镜口一圈**绿→紫渐变光环**作为科技点睛。
- **材质**：机壳哑光UV漆抗指纹；采集头铝合金阳极氧化（金属冷质感 = 高端）。
- **细节**：隐藏式出风、无可见螺丝（卡扣+内部锁付）、底盘内收"悬浮感"。
- **照明**：电源键呼吸灯、镜口光环、握柄状态灯——三处统一品牌色语言。

## 五、开模与装配

### 开模工艺
| 件 | 小批/打样 | 量产 | 要点 |
|---|---|---|---|
| 采集头壳 | CNC 铝 | 压铸铝 | 拔模 1.5°、加强筋、壁厚 2.5；阳极氧化前需喷砂 |
| 机箱大壳 | CNC/3D打印手板 | 注塑 ABS+PC | 大面防缩水：均匀壁厚 3.0 + 内部筋网；分模线沿散热槽 |
| 显示边框 | CNC | 注塑 | VESA 嵌件预埋 |
| 底盘 | 钣金折弯/焊接 | 钣金 + ABS 包覆件 | 钢架承重，外覆塑件做造型 |
| 握柄 | 硅胶手板 | 硅胶二次包胶(包覆在骨架上) | 手感 + 防滑 |

### 装配序列（见爆炸图）
`⑤底盘 → ⑥电源 → ③机箱(含光源引擎) → ④显示 → ②平衡臂 → ①采集头`
- 液芯光导 + 信号线**贯穿 ②→③→①**，机箱内对接耦合器与采集卡。
- 紧固：壳体卡扣 + 内部 M3/M4 锁付；接地线先于功能线连接。
- 出厂校准：光源功率标定、CMOS 暗场/平场校正、200mm 工作距离对焦标定。
